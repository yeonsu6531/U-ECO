# Green Campus Map

카카오맵 실시간 API 위에 우리 팀 데이터(건물, 분리배출함, 아나바다 위치)를 커스텀 마커로
얹는 방식입니다. 화면 캡처가 아니라 정식 API 호출이라 저작권 문제가 없습니다.

## 폴더 구조

```
green-campus-map/
├── index.html          메인 화면 (지도 열기 버튼)
├── map.html             실제 지도 화면 (카카오맵 실시간 로딩)
├── css/style.css        전체 디자인
├── js/config.js         ★ 카카오 API 키, 캠퍼스 중심 좌표 (제일 먼저 채울 파일)
├── js/data.js            건물/쓰레기통/아나바다 위치 정보
├── js/script.js          지도 동작 스크립트 (건드릴 필요 거의 없음)
└── assets/icons/          map, info, pin, recycle, anabada 아이콘
```

## 내가(팀) 해야 할 일

### 1. 카카오 개발자 콘솔에서 JavaScript 키 발급 — 가장 먼저 할 일
1. https://developers.kakao.com 접속 → 로그인 → 내 애플리케이션
2. 이미 앱이 있다면 그거 써도 되고(계정당 앱 여러 개 생성 가능, 개수 제한 없음), 새 앱을 만들어도 됩니다
3. 앱 선택 → **앱 키** 메뉴에서 **JavaScript 키**를 복사 (REST API 키 아님, 헷갈리기 쉬우니 주의)
4. 왼쪽 **플랫폼** 메뉴 → **Web 플랫폼 등록** → 실제 배포 주소를 등록
   - 예: `https://yeonsu6531.github.io`
   - 이 등록을 안 하면 지도가 그냥 하얗게 빈 화면으로 나옵니다 (에러 메시지도 콘솔에 안 뜨는 경우가 많아서 제일 많이 놓치는 단계)

### 2. `js/config.js`에 키 넣기
```js
const KAKAO_APP_KEY = "여기에_발급받은_JavaScript_키를_넣으세요";
```
이 자리에 1번에서 복사한 키를 붙여넣으면 끝입니다.

### 3. 건물 좌표 찍기
1. `map.html`을 열고(GitHub Pages 배포 후 실제 웹에서) 우측 상단 **"좌표 찾기 모드"** 버튼을 누릅니다.
2. 지도에서 건물 위치를 클릭하면 화면 아래에 `lat: 35.5447, lng: 129.2564` 같은 좌표가 뜹니다.
3. 이 값을 `js/data.js`의 해당 건물 항목에 그대로 넣으면 됩니다.
   (카카오맵 웹사이트에서 건물을 우클릭해도 "여기 좌표 복사" 메뉴로 바로 얻을 수 있습니다.)

> **지금 `js/data.js`에 들어있는 좌표는 전부 임시 추정치입니다.**
> 행정본관·아산도서관 신관 등 실제 위치와 다를 수 있으니, 반드시 위 방법으로 다시 찍어서
> 정확한 좌표로 교체해주세요.

### 4. `js/data.js`에 건물 정보 채워 넣기
```js
{
  id: "bldg-01",
  name: "행정본관",           // 화면에 보일 건물 이름
  number: "26호관",            // 호관 번호
  lat: 35.5447,                 // 좌표 찾기 모드에서 확인한 값
  lng: 129.2564,
  hasTrashBin: true,            // 이 건물에 분리배출함이 있으면 true
  trashInfo: "1층 로비 옆 / 3층 엘리베이터 앞", // info 아이콘 눌렀을 때 보일 설명
},
```
- `hasTrashBin: true`인 건물은 지도에 recycle 아이콘이 자동으로 옆에 같이 표시됩니다.
- 학교 공식 캠퍼스맵 페이지(ulsan.ac.kr → 캠퍼스맵)의 건물 목록·층별안내 텍스트를
  그대로 참고해서 채우면 됩니다. (텍스트 정보는 저작권 문제 없이 활용 가능)

### 5. 아나바다 등 특수 지점 확인
`SPECIAL_SPOTS`에 아나바다 행사장이 "도서관 신관~본관 사이"로 미리 넣어져 있습니다.
좌표 찾기 모드로 정확한 위치를 다시 찍어서 lat/lng 값만 맞게 조정하면 됩니다.

## GitHub Pages로 배포하는 방법

1. GitHub 레포지토리 생성 (이미 만들었다면 이 단계는 생략)
2. 이 폴더 안의 파일 전부를 **레포 최상위**에 업로드 (폴더째 올리지 말고, 안의 내용물을 올릴 것)
3. 레포의 **Settings → Pages** 이동
4. **Branch**를 `main`, 폴더는 `/ (root)`로 설정 후 저장
5. 배포 주소가 나오면 그 주소를 1번의 카카오 콘솔 **Web 플랫폼**에 등록 (이 순서가 중요합니다 —
   배포 주소를 먼저 알아야 카카오 콘솔에 정확히 등록할 수 있어요)

## 팀원과 같이 작업하기
- GitHub 레포 Settings → Collaborators에 팀원 계정 추가
- `js/data.js`(건물 정보)와 `js/config.js`(키, 최초 1회만) 정도만 주로 수정하면 되므로
  충돌이 거의 없습니다

## 나중에 확장하고 싶다면 (지금은 구현 안 함)
- **내 위치(pin.png) 표시**: `js/script.js`의 `renderMyLocationPin(lat, lng)` 함수가
  이미 준비되어 있습니다. `navigator.geolocation.getCurrentPosition()`으로 받은 좌표를
  그대로 넣어 호출하면 바로 동작합니다 (위경도 기반이라 별도 환산이 필요 없어졌습니다).

# Green Campus Map

외부 지도 API 없이, 정적 이미지 위에 좌표를 찍는 방식으로 만든 캠퍼스 지도 웹사이트입니다.
GitHub Pages에 그대로 올리면 바로 작동합니다.

## 폴더 구조

```
green-campus-map/
├── index.html          메인 화면 (지도 열기 버튼)
├── map.html             실제 지도 화면
├── css/style.css        전체 디자인
├── js/data.js            ← 건물/쓰레기통/아나바다 위치 정보 (여기만 수정하면 됨)
├── js/script.js          지도 동작 스크립트 (건드릴 필요 거의 없음)
└── assets/
    ├── campus-map.jpg    캠퍼스 지도 이미지 (지금은 플레이스홀더, 교체 필요)
    └── icons/             map, info, pin, recycle, anabada 아이콘
```

## 내가(팀) 해야 할 일

### 1. 캠퍼스 지도 이미지 준비 — 가장 먼저 할 일
`assets/campus-map.jpg` 를 실제 울산대학교 지도 이미지로 교체하세요.
- 학교 홈페이지의 공식 캠퍼스 안내도 캡처, 또는
- 손으로 그린 단순화된 캠퍼스 배치도
- 가로가 긴 형태(가로:세로 약 3:2 정도)가 화면에 제일 잘 맞습니다.
- 파일 이름은 반드시 `campus-map.jpg` (다른 이름을 쓰려면 map.html의 `src` 경로도 같이 바꿔야 함)

### 2. 건물 좌표 찍기
1. `map.html`을 열고(더블클릭해도 웹브라우저에서 바로 열림) 우측 상단 **"좌표 찾기 모드"** 버튼을 누릅니다.
2. 지도 위에서 건물 위치를 클릭하면 화면 아래에 `x: 42.0, y: 55.0` 같은 좌표가 뜹니다.
3. 이 값을 `js/data.js`의 해당 건물 항목에 그대로 넣으면 됩니다.

### 3. `js/data.js`에 건물 정보 채워 넣기
지금은 예시 데이터(본관, 도서관 신관, 학생회관, 공학관)가 들어가 있습니다. 실제 건물 목록으로 교체하세요.

```js
{
  id: "bldg-01",
  name: "본관",              // 화면에 보일 건물 이름
  number: "1호관",            // 호관 번호
  x: 42,                      // 좌표 찾기 모드에서 확인한 값
  y: 55,
  hasTrashBin: true,          // 이 건물에 분리배출함이 있으면 true
  trashInfo: "1층 정문 로비 옆 / 3층 엘리베이터 앞", // info 아이콘 눌렀을 때 보일 설명
},
```
- `hasTrashBin: true`인 건물은 지도에 recycle 아이콘이 자동으로 같이 표시됩니다.
- 건물을 더 추가하려면 이 형식 그대로 배열에 객체를 하나 더 추가하면 됩니다.

### 4. 아나바다 등 특수 지점 확인
`SPECIAL_SPOTS`에 아나바다 행사장이 "도서관 신관~본관 사이"로 미리 넣어져 있습니다.
좌표 찾기 모드로 정확한 위치를 다시 찍어서 x, y 값만 맞게 조정하면 됩니다.

## GitHub Pages로 배포하는 방법

1. GitHub에서 새 레포지토리 생성 (예: `green-campus-map`)
2. 이 폴더 안의 파일 전부를 그 레포에 업로드 (드래그 앤 드롭으로도 가능)
3. 레포의 **Settings → Pages** 이동
4. **Branch**를 `main`(또는 `master`), 폴더는 `/ (root)`로 설정 후 저장
5. 몇 분 뒤 `https://아이디.github.io/green-campus-map/` 주소로 접속하면 바로 확인 가능

## 팀원과 같이 작업하기 (Google Drive 관련 질문 이어서)
코드 파일은 Google Drive보다 **GitHub 레포 자체를 공유**하는 게 맞습니다.
- 레포 Settings → Collaborators에 팀원 GitHub 계정 추가
- 각자 `js/data.js`만 수정해서 커밋하면 충돌이 거의 없습니다 (한 파일에 데이터만 몰려 있어서)

## 나중에 확장하고 싶다면 (지금은 구현 안 함)
- **내 위치(pin.png) 표시**: `js/script.js`의 `renderMyLocationPin(x, y)` 함수가 이미 준비되어 있습니다.
  브라우저의 `navigator.geolocation.getCurrentPosition()`으로 위치를 받아서, 그 좌표를
  지도 이미지 기준 %로 환산해 이 함수에 넣어주기만 하면 됩니다. (다만 위경도를 이미지 좌표로
  정확히 환산하려면 지도 이미지의 실제 위경도 기준점 2곳이 필요해서, 우선순위는 낮게 둬도 됩니다.)
